# Contributing

Fork this repository, make a focused change on a branch, and open a pull request
against `main`. Include the problem, resulting behaviour and relevant checks.

Run the checks in the README. Changes to assignments also require the Python
API tests. Keep student and teacher data, saved links, database files, credentials
and private exam source materials out of commits and screenshots.

The sole merge maintainer is `@sitnstudy`. Public contributors do not receive
write access, database access or production deployment secrets. Pull-request
checks run without production credentials. CI does not deploy contributions.

Contributions to original software are provided under the repository's MIT
license. Retain third-party notices and include licensing evidence for added
assets.
